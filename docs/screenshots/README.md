## Guidelines

- Prefer **light UI**, English locale if possible (broader GitHub audience).
- Crop to the app window; avoid personal real-family PII — use fictional sample people.
- Suggested width ≈ **1200–1600px**; keep file size reasonable (PNG or compressed).
- Do not commit original RAW exports larger than needed.

Until these files exist, GitHub will show broken-image placeholders in the README.
